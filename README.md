# Sanoori Trading

Sanoori Trading is a Bangladesh-based supplier of:

- Sanitary Ware
- Tiles
- Building Materials

## Features

- **Product Catalogue** — Browse sanitary ware, tiles, and building materials by category
- **Category Browsing** — Explore products through organized categories
- **Product Details** — View product images and product information
- **Product Inquiry / Price Request** — Send inquiries for products
- **WhatsApp & Contact Options** — Contact Sanoori Trading directly
- **Responsive Website** — Designed for desktop, tablet, and mobile

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the website locally.
